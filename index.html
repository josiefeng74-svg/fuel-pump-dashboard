防守方作战原则

先判断攻击发生在哪一层：流量 → 转化 → 价格 → 口碑 → 库存 → Listing → ASIN → Account。越靠后，优先级越高。任何涉及ASIN不可售、Account Health、IP/安全/合规的事件，立即高于价格战和广告战。
执行规则：每一种攻击都必须回答 5 个问题：①识别信号是什么；②2小时内止血什么；③24小时内修复什么；④7天内如何恢复；⑤什么情况升级给Cherry。

一、常规打法｜详细防守措施

1. 价格战 / Coupon压价高概率
识别信号
竞品主力SKU降价、Coupon加深、Deal频率提高；我方曝光稳定但CVR下滑；核心词位置未变但订单下降。
0–2小时
Cherry/Josie先拆“价格是否为主因”：对比价格差、CVR、CTR、核心词排名和竞品销量，不直接全线跟价。
24小时
按SKU分层：现金牛主SKU优先守价值；低价防御SKU承接价格敏感流量；必要时用短期Coupon替代永久降价。
7天动作
用利润模型验证降价后的贡献利润、TACOS和份额改善；无明显份额回升则撤销无效促销。
红线
若锂电市占持续逼近30%且CVR显著受价格差影响，升级为战役级价格防守；亏损打法必须时间盒管理。
Owner
Cherry + Josie定策略；Rocky提供可降价成本空间。
2. 广告抢词 / 核心关键词截流高概率
识别信号
核心词自然位/广告位下降、CPC快速上升、竞品广告占位增多，CTR尚稳但流量减少。
0–2小时
把问题拆成品牌词、核心泛词、场景词；先保护品牌词和转化最好的核心词，不平均加预算。
24小时
核心ASIN独立预算；提高高转化词防守优先级；低效词降价或暂停；SP/SB/SD分层看，不让无效流量拖累利润。
7天动作
复盘关键词份额、CPC、CVR、TACOS、自然位是否恢复；把站外品牌搜索增长与Amazon品牌词防守联动。
红线
核心词连续7天跌出目标位且订单同步下降，升级专项；禁止用无上限CPC硬抢排名。
Owner
Cherry + Josie。
3. 新品包围 / 高配低价高威胁
识别信号
竞品集中上新5–6GPM、Auto-stop、手自一体、多供电、防漏结构；新品Review和BSR快速爬升。
0–2小时
美辰建立新品对比卡：价格、GPM、控制方式、供电、管长、评分、Review、类目位、卖点。
24小时
Kemal判断是真需求还是参数堆料；只对影响转化的核心功能启动产品解法，不跟所有功能。
7天动作
形成“主力款+防御款+升级款”路线；必要时先通过Listing/视频把已有优势表达清楚，再决定硬件升级。
红线
竞品新品连续2周抢走核心词、BSR和份额，进入产品升级战；Kemal/Rocky给出改款周期与成本。
Owner
美辰 → Kemal → Rocky → Cherry/Josie。
4. 评分 / Review优势攻击当前薄弱点
识别信号
竞品稳定4.3–4.5★，我方约4.0★；竞品内容集中强调“不漏油、可靠、耐用”；我方CVR随差评增加下降。

红线
核心ASIN星级跌破4.0或Leak投诉明显放大，产品改善优先级高于广告扩量。
Owner
Kemal + Rocky产品根因；Cherry/Josie控制流量和Listing表达。

二、极端打法｜详细防守措施

极端战判断标准：只要出现“ASIN不可售 / 多ASIN同时异常 / Account Health恶化 / IP或安全合规投诉 / Listing被非预期篡改 / 账户权限或收款异常”，立即从常规经营切换为战时响应。此时第一目标是保店铺、保链接，不再以短期销量为第一目标。
1. IP / 商标 / 版权 / 专利投诉致命
识别信号
收到Performance Notification、IP Complaint、商品被移除、主图/文案被要求修改。
0–2小时
Cherry冻结非必要Listing改动；确认投诉类型、权利人、涉及ASIN和具体内容；调用对应ASIN战备包。
证据包
商标/授权链、设计源文件、图片/视频源文件、专利检索/授权资料、采购与供应链凭证、历史Listing快照。
24小时
按平台指控逐项回应，不写泛泛解释；必要时由专业法务/知识产权顾问确认权利边界。
业务承接
其他正常ASIN承接合法广告和自然流量；不要为绕过处罚临时创建新账号/链接。
Owner
Cherry牵头；Kemal提供产品/IP材料；Josie参与运营承接。
2. 产品安全 / 合规投诉致命
识别信号
出现Safety Complaint、危险使用/泄漏/火灾风险相关通知，或平台要求测试/合规文件。
0–2小时
立即核对产品批次、投诉内容和真实风险；对可能存在真实安全缺陷的批次优先安全处置，不先争论流量。
证据包
检测/合规文件、说明书、安全警示、适用液体、批次QC、产品实拍、材料/密封结构、供应商记录。
24小时
Kemal+Rocky判断是否存在真实产品根因；若有，给出纠正措施、批次隔离和预防措施；若无，提交对应事实证据。
红线
涉及真实安全风险时停止扩量，安全结论高于市场份额目标。
Owner
Cherry总协调；Kemal/Rocky主导事实与整改。

0–2小时

24小时
逐项核对不同GPM、手动/自动/手自一体是否符合当前变体主题；不为保Review强行维持高风险变体。
长期防守
每周保存父子体结构和关键属性快照；新品上线前做Variation/Browse Node自查。
Owner
Cherry + Josie运营判断；Kemal确认规格实质差异。
4. Listing被篡改 / 关键属性异常致命
识别信号
标题、主图、品牌、类目、兼容性、成人标记、危险品属性、包装数量等无授权变化。
0–2小时
截图/导出前台和后台差异；冻结团队多人同时修改；确认最近权限/贡献来源。
24小时

长期防守
关键字段每日/每次变更后快照；最小权限；高风险字段变更双人复核。
Owner
Cherry。

2小时内

强MFA、最小权限、管理员白名单；收款/品牌/高权限变更双人复核；第三方服务定期清理。

供应链谈判

阶梯价：1× / 1.5× / 2× / 3×采购量分别锁价。
锁产能：旺季产能≥预测峰值1.5×。
锁交期：正常/加急/极限交期分档。
质量责任：漏油、寿命、适配写入验收/赔付。
备选供应商：完成第二供应源测试。

利润模型

贡献利润 = 销售额 − 产品成本 − 头程/关税 − Amazon费用 − 广告 − Coupon/Deal − 退货损失 − 站外获客 − 其他可变成本。
正常经营：利润≥目标值。
防守1级：低于目标但为正，可短期加预算。
防守2级：接近0，仅守核心词/核心SKU。
极限状态：≤0必须Cherry牵头决策并设置时间盒止损。
