漏油问题闭环

自动停机不准

评估更高精度传感器；在不同油品、温度、倾角、泡沫条件下验证停机准确率。

软管长期破损

对比耐油胶管、防腐材质及同类专业软管；做耐油浸泡、弯折、低温、拉脱和寿命测试。

连接处渗漏

优化连接与密封结构，评估一体式/高可靠密封方案；验证压力、跌落、振动和装配公差。

结构权衡

在密封可靠性、体积、收纳、维护和成本之间确定平台架构。

液体兼容与安全边界

输水与输油的材料、防腐、密封要求不同，不默认宣传“水油通用”。

汽油/柴油：核验泵体、密封、软管、电气部件的材料兼容与安全要求，并在说明书和页面明确适用/禁用液体。

机油/润滑油：关注黏度变化对流量、电机负载和吸程的影响。

水及其他液体：独立评估材料与腐蚀风险，未经验证不沿用燃油泵结论。

常规防守

价格战

先判断对CVR/份额的真实影响；优先供应链降本、局部SKU和阶段性促销，不机械跟价。

广告抢词

守品牌词、核心高转化词和主ASIN；按CPC/CVR/TACOS动态配置预算。

新品 / 高配低价

拆功能差异，决定现有款应对、升级款补位或不跟随。

评分 / 转化 / 库存

真实VOC进入产品闭环；核心ASIN不断货；Listing强化可验证的质量与场景优势。

极端事件防守

优先级：保账户 ＞ 保链接 ＞ 保库存/利润 ＞ 保排名。
IP / 安全 / 合规投诉

核对具体指控，准备合法权利、供应链、检测、包装、说明书和实拍证据，按平台流程申诉。

Listing / 类目异常

每日关键字段快照；冻结非必要编辑；通过品牌与官方支持恢复。

异常订单 / 退货 / VOC

聚类分析并保留证据；真实质量问题进入整改，异常模式向平台报告。

ASIN下架 / 账户风险

快速分型、证据树、正常ASIN承接流量；重大Account Health事件优先恢复账户。

3独立产线 + 新供应商开发争取独立产线/独立物料管理，保护我司产品信息；同时开发具备更好品控资质的新供应商。市场重要功能反馈优先联合改进。

5知识产权防御梳理供应商和我司合法专利/商标权利；发现真实侵权时由法务评估并通过平台或司法渠道处理，避免无依据投诉。
6公开竞争情报通过公开、合法渠道了解主要竞品的产品、供应链能力、工厂资质、交期和规模信号；不获取或使用他方商业秘密或非公开客户信息。
7新品源头工厂雷达供应链协同运营持续跟踪市场新品，定位公开可识别的源头工厂，评估其资质、品控、产能、技术能力和我司可复制/升级空间。
8品牌与海关合规防线提前完成我司品牌、核心市场类别和必要海关备案；监控真实侵权风险并依法维权，不抢注他人品牌或利用备案阻断合法竞争。
9培养核心战略伙伴筛选像“先凯”这类可靠伙伴，建立新品优先开发、重点项目优先排产、成本优化共享、质量改善共担、市场反馈优先响应和规模收益共享机制，形成长期利益共同体。
供应链目标：不是单纯压价，而是形成“成本优势 + 产能确定性 + 信息保护 + 质量改善 + 新品速度 + 战略伙伴”的综合护城河。
