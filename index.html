常规打法｜防守方应对

价格战

先判断竞品降价是否真实影响我方CVR/份额；不机械跟价。测算$55基准下不同售价的利润和销量弹性；优先用Coupon、核心SKU局部应战、供应链降本。若需要进入亏损区，必须计入$33K战役额度。

广告抢词

守品牌词、核心高转化词和主ASIN；监控CPC/CVR/TACOS。竞争加剧但转化未下降时不盲目抬价；预算优先给能守自然位的词。

新品 / 高配低价

美辰识别新品爬升，Kemal拆功能差异；运营决定是用现有ASIN应对、推出升级款还是不跟。避免用全部老品同时迎战。

评分与转化战

主抓真实VOC和漏油根因；Review异常与真实产品问题分开处理。Listing强化适用场景、兼容性、操作方式和防漏改善证据。

库存 / 侧翼 / 站外

Rocky保障核心ASIN不断货；Ecarke承接侧翼；Google、Meta、TikTok、YouTube和独立站用于品牌搜索、需求制造与再营销，不以无底线低价作为唯一手段。

极端打法｜防守方应对

优先级：保账户 ＞ 保链接 ＞ 保库存/利润 ＞ 保排名。 极端事件发生时停止无关改动，统一由Cherry升级指挥。
IP / 安全 / 合规投诉

立即确认具体指控；调取商标/专利/版权、供应链、检测、包装、说明书、产品实拍等证据；围绕平台具体问题申诉，不使用泛化模板。

Listing篡改 / 变体 / 类目异常

使用每日关键字段快照比对异常；冻结非必要编辑；通过品牌和官方支持渠道恢复正确属性并保留时间线。

异常订单 / 退货 / VOC / NCX

按时间、SKU、退货原因、地址/订单模式聚类；真实质量问题进入产品整改，异常模式保留证据并向平台报告；同时保护主ASIN可售状态。

核心ASIN下架

0–30分钟确认事实；2小时内完成分型和证据树；正常ASIN承接流量；恢复后按7/14/30天计划逐步恢复广告、自然位和库存。

账户权限 / 店铺停用风险

强MFA、最小权限、收款变更双人复核；出现重大Account Health事件时升级账户战，短期销售让位于账户恢复。

利润模型

贡献利润 = 销售额 − 产品成本 − 头程/关税 − Amazon费用 − 广告 − Coupon/Deal − 退款损失 − 站外获客 − 其他可变成本
