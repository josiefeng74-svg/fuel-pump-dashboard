产品策略｜总览

核心：场景分层 + 漏油治理 + 差异化产品矩阵。
聚焦汽车/SUV/大卡车、农用/园林、船舶三大核心场景；以漏油治理建立质量底座，以流量、供电、防水和智能化形成分层产品组合。
策略版块核心判断策略动作预期结果
市场聚焦需求差异来自车辆/设备、油桶容量、供电条件及环境围绕三大核心场景定义产品；工业仅作为辅助/应急资源集中、定位清晰
产品分层流量并非越大越好，应与场景匹配建立入门、技术升级、专业耐用、智能差异化等产品梯队覆盖价格带与功能带
质量突破漏油是自动款、手自一体款核心差评升级传感器、管路材质、密封结构并专项验证降低退货与差评，支撑溢价
技术差异化创新必须可感知、可传播定量/计量、数显、多档流量、超大流量等形成系列化卖点

漏油问题闭环

自动停机不准

评估更高精度传感器；在不同油品、温度、倾角、泡沫条件下验证停机准确率。

软管长期破损

对比耐油胶管、防腐材质及同类专业软管；做耐油浸泡、弯折、低温、拉脱和寿命测试。

连接处渗漏

优化连接与密封结构，评估一体式/高可靠密封方案；验证压力、跌落、振动和装配公差。

结构权衡

在密封可靠性、体积、收纳、维护和成本之间确定平台架构。

液体兼容与安全边界

输水与输油的材料、防腐、密封要求不同，不默认宣传“水油通用”。

汽油/柴油：核验泵体、密封、软管、电气部件的材料兼容与安全要求，并在说明书和页面明确适用/禁用液体。

机油/润滑油：关注黏度变化对流量、电机负载和吸程的影响。

水及其他液体：独立评估材料与腐蚀风险，未经验证不沿用燃油泵结论。

Amazon恶意攻击防御手册｜详细版

防守原则：不以违规方式反击。优先级为 保账户 ＞ 保链接 ＞ 保库存/利润 ＞ 保排名。所有异常先留证、再分型、再止血、再走Amazon官方申诉/法务流程。
风险类型典型识别信号风险详细防守动作
差评集中爆发短期差评频率显著高于历史；内容模板化；与真实VOC不一致中高记录星级、Review数量和内容变化；核对订单/VOC；真实质量问题立即整改；可疑模式整理证据后提交平台。
投诉 / Account Health异常投诉集中、ASIN或账户出现政策警告高第一时间调出订单、批次、检测、说明书和页面历史；确认投诉类型，必要时由法务/合规介入。
异常订单 / 退货集中高客单集中下单、地址异常、短期大量退货或拒付高建立订单异常规则；保留物流、签收、序列/批次信息；异常模式提交平台调查。
VOC / NCX异常上升退货原因或负面体验短期跳升高按ASIN/批次/原因拆分；真实问题快速CAPA；异常模式与订单/Review交叉验证。
Listing异常修改标题、类目、属性、兼容信息或图片无授权变化高核心ASIN关键字段快照；发现异常冻结非必要编辑，通过品牌支持恢复并保存Case链路。
IP / 安全投诉收到IP Complaint、产品安全或认证问题极高预先建立权利、检测、认证、采购链路证据包；按具体问题通过官方流程回应。
广告异常点击暴增但转化下降、CPC异常中高按词、时段、Placement和Campaign监控；设置预算上限；异常时保存报表并反馈。
ASIN / 账户级风险不可售、搜索消失、重大政策警告极高停止非必要高风险操作；账户恢复优先于单ASIN；统一事实时间线、根因、整改和预防措施。
